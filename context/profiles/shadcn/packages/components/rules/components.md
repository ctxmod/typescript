# shadcn Component Context

Shadcn/ui integration and design token architecture for component files.

shadcn integration covers the ownership model, the one-per-project primitives library (Base UI by default for new projects, Radix still supported), the CLI and registries, CVA variants, and the cn() utility. Design token architecture defines the three-layer token system and semantic naming conventions. Loading, error, empty, and success states rendered by a component follow the es-owned honest-state and error discipline.
